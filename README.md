# 👋 Hey, I'm Hassaan

I'm a student developer and the creator of **EchoSearch** and **Echo AI**.

I enjoy building projects from the ground up, whether that's a search engine, AI tools, Android applications, or websites. Most of my work revolves around creating fast, useful, and accessible experiences using modern web technologies.

- 🔭 **Currently Building:** EchoSearch & Echo AI
- 🌐 **Website:** https://echo-search.net
- 🤖 **AI Project:** https://echo-search.net/essentials/echo_ai
- 📱 **Learning:** Android development with Kotlin
- ⚡ **Favourite Technologies:** HTML, CSS, JavaScript, Kotlin, and Gradle
- 🚀 **Long-Term Goal:** Build a powerful independent search ecosystem
